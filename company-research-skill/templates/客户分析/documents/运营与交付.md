# 宁德时代｜运营与交付
> 数据来源：年报、行业标准

## OPERATING MODEL
### 产能、价值链与关键交付流程
公司属于全球化动力电池制造企业，覆盖研发、材料、电芯、PACK与储能系统制造。价值链覆盖锂电材料采购、电芯制造、系统集成、质量管理与全球客户交付。当前重点关注全球产能布局、供应链稳定与制造效率优化。

## 01 运营核心指标
| 指标 | 数值 | 说明 |
| ---- | ---- | ---- |
| 产能/服务能力 | 772GWh 2025全球产能 | 全球在建+已投产总产能 |
| 产能利用率 | 96.9% 2025产能利用率 | 整体产能利用率保持高位，部分海外新工厂爬坡中 |
| 交付周期 | 约90天 平均周期 | 从订单确认到电池包交付，储能项目周期更长 |
| 关键基地 | 75+ 覆盖国家和地区 | 销售覆盖；生产基地分布在中国、德国、匈牙利、美国等 |

## 02 价值链结构
01 **供应商【原材料 / 外部服务】**
上游包括锂矿、钴、镍、石墨、电解液、隔膜、铜铝箔等材料供应商；设备供应商、检测服务商、工程建设服务商。与核心原材料供应商签订长协锁量。

02 **采购【采购模式】**
集团集中大宗原材料采购 + 区域本地化采购结合；战略长协采购锁定锂、镍等资源，分散采购对冲单一供应商风险。

03 **生产/服务【核心生产环节】**
正极/负极材料预处理 → 极片制造（涂布、辊压、分切） → 电芯装配（卷绕/叠片、注液、化成） → 电芯检测分选 → PACK电池包组装、BMS集成、系统测试。

04 **仓储/物流【交付模式】**
国内整车厂就近基地JIT准时配送；海外采用海运+区域仓储；储能项目采用整车批量交付，大型项目现场配套交付。

05 **客户【终端客户】**
新能源车企OEM、电网/工商业储能运营商、换电运营企业。

## 03 产能与资源布局
### 核心基地/资源
- **【基地/区域A：国内基地（福建、四川、江苏等）】【占比约65%】**：国内主要电芯与PACK产能，配套国内车企客户，供应链配套完善。
- **【基地/区域B：欧洲基地（德国、匈牙利）】【占比约22%】**：服务大众、宝马等欧洲车企，规避欧洲关税，本地化生产。
- **【基地/区域C：北美、东南亚基地】【占比约13%】**：美国、印尼等在建/投产基地，服务北美车企与储能客户，对冲贸易壁垒。

### 运营约束
- **【原材料/供应链约束】**：锂、镍、钴等金属价格波动；关键材料、设备海外供应存在地缘风险。
- **【产能扩张约束】**：新建工厂资本投入巨大，产线爬坡周期长，海外建厂审批、环评周期漫长。
- **【人工/技能人才约束】**：高端工艺、智能制造、电池研发专业人才缺口；海外工厂本地熟练工人招聘难度高。
- **【质量/合规要求】**：欧盟电池法规、北美安全法规、碳足迹、环保合规要求持续提升，增加合规成本。
- **【物流/交付约束】**：海外海运周期长、运费波动；大型储能项目交付受现场工程进度影响。

## 04 关键运营流程
| 流程 | 核心环节 | 关键指标 | 面临问题 | 数字化程度 |
| ---- | ---- | ---- | ---- | ---- |
| 需求/订单 | 需求预测 + 接单 | 订单预测准确率 | 车企订单波动大，预测偏差 | 【高】ERP+产销协同系统 |
| 采购 | 供应商 + 采购 | 采购成本、交付准时率 | 原材料价格波动、供应商交付延期 | 【高】供应链协同平台 |
| 生产/服务 | 生产/服务交付 | 良率、效率 | 新产线良率爬坡、设备停机 | 【高】智能工厂MES系统 |
| 交付 | 仓储 + 物流 + 客户 | 准时交付率 | 跨境物流延迟、项目验收滞后 | 【中高】仓储物流管理系统 |
