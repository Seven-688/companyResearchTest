# 调研工作流

## 检索策略

### Bootstrapping（开始任何模块前必做）

先建立公司基线事实，作为后续所有模块的锚点：

1. 公司官网（About / 业务 / 新闻）
2. 最新年报或财报（搜索"<公司名> 年报/年度报告 排版日期"或 `annual report <company> <year>`）
3. 基础信息页（<公司名> 维基百科 / 天眼查 / 企查查 / Bloomberg 摘要等）

一次 Bootstrapping 检索应产出：成立年份、总部、上市与否及代码、主营业务一句话、股权/实控人、近一年营收量级。若这些不稳定（不同来源冲突），记录冲突并继续。

### 关键词构建技巧

用三种关键词组合每个模块的查询：

- **公司名 + 模块词**：`<公司> 年报`、`<公司> 前五大客户`、`<公司> 产能利用率`
- **公司名 + 动作**：`<公司> 增资`、`<公司> 收购`、`<公司> 中标`、`<公司> 行政处罚`
- **海外公司用英文**：`<company> annual report`、`<company> top customers`、`<company> debt rating`

### 交叉验证规则

- **关键数字**（营收、利润、市占率、员工数、产能）至少 2 个独立来源
- **不一致处理**：都写进报告并标注差异（如"A 来源披露 100 亿，B 来源 95 亿，差异或为口径不同"）
- **单一来源的断言**注明来源，不当作确定性事实
- **传闻/未证实信息**：写"据报道"，给出处，并注明无法独立核实

## 模块化时间管理

每模块预算约 3-5 次检索。总检索轮次控制在 30 次以内（标准深度，约 10-20 个有效来源）。若某一模块 3 次检索无实质进展，标注"未获取公开信息"继续下一模块，不要无限烧轮次。

## 报告写作要求

- 语言：纯中文（专有名词首现括号注原文）
- 每个关键数字 ± 来源编号
- 事实与推断分离："推断"内容单独成段或加标记
- 来源清单：编号 + 名称 + URL + 访问日期
- 数据时间戳：写明数据对应财年/时点，不同年份数据并列时要标注

## 输出前自查清单

提交报告前逐项确认：

- [ ] M1 公司介绍：成立/总部/上市状态/股权/业务构成齐全
- [ ] M2 财务：近 2-3 年趋势 + 盈利结构 + 现金与风险
- [ ] M3 客户与销售：客户是谁/怎么买/怎么付，集中度
- [ ] M4 行业：市场/周期/政策/格局
- [ ] M5 竞争对手：对手/位置/路线/对比简表
- [ ] M6 运营交付：产能/价值链/关键流程
- [ ] M7 IT/数字化：系统/投入/规划/在位供应商
- [ ] M8 机会判断：战略张力/机会池与优先级/不做什么
- [ ] 关键数字都有来源编号，来源清单完整可点
- [ ] 事实与推断已分离，推断可回溯到事实
- [ ] 未获取的信息已标注，无编造数据
- [ ] 报告为单文件 HTML，纯中文，双击可开
