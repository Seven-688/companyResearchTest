# 宁德时代｜客户与销售
> 数据来源：宁德时代年报、招投标公告、行业调研纪要

## 一句话总述
客户覆盖全球新能源汽车与储能市场。公司主要客户包括新能源汽车OEM与储能领域客户，采用B2B直销模式，并持续拓展全球客户合作。

### 核心指标卡片
| 指标 | 数值 | 说明 |
| ---- | ---- | ---- |
| 前五客户占比 | ~30% | 客户集中度中等，持续分散客户结构，降低单一客户依赖 |
| 直销占比 | >95% | 以B2B直销为主，几乎不通过经销商渠道销售 |
| 平均账期 | 约90天 | 车企客户账期偏长，储能项目客户账期差异较大 |
| 区域覆盖 | 国内+海外75+国家 | 国内全部省份；海外覆盖欧洲、北美、东南亚等 |

## 客户结构
### 核心客户
- 宝马（BMW）
- 大众（Volkswagen）
- 理想汽车
- 吉利汽车
- 特斯拉、福特、现代、蔚来、小鹏、比亚迪（部分供应）、大型储能运营商（国家能源集团、阳光电源等）

### 客户类型
- **B2B / B2C**：全部为B2B模式，不直接面向终端个人消费者
- **政府客户**：国内电网、央企能源集团、海外公用事业储能招标项目
- **渠道客户**：极少，以直销为主，几乎无经销商渠道
- **海外客户**：海外车企、欧洲/北美大型储能开发商，海外收入占比持续提升

### 区域分布
- 华东：约35%（国内车企、储能项目集中）
- 华南：约20%
- 海外：约38%（欧洲、北美、东南亚）
- 其他：约7%

## 销售模式与回款
| 销售模式 | 占比 | 特点 | 账期 | 风险 |
| ---- | ---- | ---- | ---- | ---- |
| OEM直销 | ＞95% | 平台定点与长期合作，和车企签订多年框架供货协议，锁量议价 | 60–120天 | 客户价格谈判与平台周期风险，车企压价，车型迭代带来订单波动 |
| 渠道 | ＜3% | 少量储能配套分销，占比极低 | 约60天 | 订单规模小，利润薄 |
| 项目制 | ＜2% | 大型储能电站EPC配套项目，按项目节点交付验收 | 90–180天 | 项目验收周期长、回款慢，受项目资金影响 |

## 关键观察
### 客户风险
1. 客户集中度风险：虽然前五大客户占比约30%，但头部车企议价能力极强，持续压低电池采购价格；
2. 回款压力：车企客户账期普遍较长，部分储能项目存在验收延迟、回款滞后；
3. 价格竞争风险：动力电池行业竞争激烈，比亚迪、中创新航等对手抢夺车企订单，存在丢单风险；
4. 海外地缘风险：北美、欧洲贸易政策变化，影响海外客户订单落地。

### 增长机会
1. 区域扩张：持续加大北美、欧洲、东南亚海外工厂布局，就近配套海外车企与储能客户；
2. 新客户获取：拓展海外二线车企、新兴储能运营商，持续丰富客户池，分散客户结构；
3. 渠道优化：储能业务开拓更多公用事业、工商业储能项目；换电业务拓展出行客户；
4. 产品绑定：通过长协、技术联合开发锁定客户长期订单。
